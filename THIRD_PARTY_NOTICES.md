# Third-party components

This source package uses the Python standard library and browser platform APIs. Frontend tests use Node.js built-in modules. No third-party JavaScript/Python library, font file, renderer, model, reference image, or video is bundled.

The optional media path invokes FFmpeg and ffprobe discovered on PATH. Users install those executables separately under their build's applicable LGPL/GPL and other component terms. Their binaries are not included in this package. The application does not download them automatically. See https://ffmpeg.org/legal.html for FFmpeg's licensing information.

Original interface icons are inline editable SVG paths, and the supplied storyboard example is synthetic text and timing data.
