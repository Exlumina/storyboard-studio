# Changelog

## 0.5.2

Initial standalone public source package of the generic Storyboard Studio editor. Includes inline scene editing, board and scene identities, reference media, connected-path planning, feedback, revisions, verified Mac identifier copying, strict native-return admission, and a safe loopback launcher.

Public packaging removes private policies and project/runtime data, provides synthetic setup, preserves PATH-based optional media tools, and uses a portable loopback port default. The source package does not launch a renderer or supply native production integrations.
